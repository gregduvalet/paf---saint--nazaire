# PAF — Saint-Nazaire

Projet collaboratif entre **Les Pieds dans le PAF** et **TAPAJ** 

## Objectif

Visualiser sur une carte 3D de Saint-Nazaire les lieux où des jeunes 
ont capté vidéos et sons, 
et les restituer via des fiches descriptives interactives.

Un outil de réappropriation du territoire et de prévention 
des conduites addictives par le médias audiovisuel.

## Fonctionnalités prévues
- 🗺️ Carte 3D de Saint-Nazaire (Google Maps)
- 📍 Points d'intérêt (POI) géolocalisés
- 🎬 Lecture de vidéos YouTube embarquées dans les fiches POI
- 🔊 Intégration de contenus sonores
- 📄 Fiches descriptives par lieu

## Stack technique
- Google Maps JavaScript API
- YouTube IFrame API
- Serveur (domaine autorisé pour players YouTube)
